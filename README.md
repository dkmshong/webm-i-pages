# webm-i-pages

本仓库用于归档和发布多个独立的 HTML 页面。

这些页面可能涉及不同主题或功能，彼此之间无直接关联。仓库本身不针对任何特定域名或网站，仅作为静态 HTML 资源的集中存放与版本管理。

## 项目简介

- 仓库名称：`webm-i-pages`
- 用途：归档与发布独立 HTML 页面
- 内容：多个独立的 HTML 文件及其相关资源（如 CSS、JavaScript、图片等）
- 特点：页面之间相互独立，无统一主题或框架依赖

## 目录结构说明

```
webm-i-pages/
├── page-xxx/          # 每个独立页面为一个子目录
│   ├── index.html     # 页面主文件
│   ├── style.css      # 可选样式文件
│   ├── script.js      # 可选脚本文件
│   └── assets/        # 页面专属资源
├── page-yyy/
│   └── ...
├── README.md          # 本文件
└── .gitignore         # Git 忽略规则
```

每个页面自包含在一个子目录中，便于单独浏览、修改或部署。

## 页面归档说明

- 页面内容可能来自不同时期、不同用途，保持原始形态归档。
- 部分页面可能包含外部引用（如字体、库文件），建议将依赖一并归档以避免失效。
- 归档时尽量保持文件结构简洁，避免深层嵌套。

## 维护说明

- 欢迎提交 Pull Request 添加新的独立页面（请遵循现有目录结构）。
- 如需修改已有页面，请确保不影响其他页面的正常运行。
- 不建议在页面中嵌入跟踪、统计或外部动态内容，以保持静态归档性质。
- 本仓库不提供在线演示或托管服务，仅作为代码与资源版本管理。
